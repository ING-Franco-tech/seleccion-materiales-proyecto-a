Módulo 3 de 10, sistema A1. Aislamiento anular (C2 vs C4), envolvente combinada ISO 14310, resistencia SSC y calificación de elastómeros (RGD / extrusión).

  • API Spec 11D1 / ISO 14310
  • ISO 15156-2 / -3
  • ISO 23936-2 / NACE TM0187
  • ISO 21457

Corte técnico y envolvente

  • Fluido producido en mandril (C1) y gas ácido inferior (C2)
  • Fluido de empaque inhibido alcalino sobre el packer (C4, pH 9.5-10.5)
  • Triple sello elastomérico + respaldos anti-extrusión y pasaje capilar 3/8"
  • Cuñas bidireccionales (Slips) de Packer y Ancla de Tubería (TAC)
